# 11 DeepSeek-R1: learn to reason from answers that can be checked

Paper: [DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning](https://arxiv.org/abs/2501.12948), DeepSeek-AI (2025). [PDF](https://arxiv.org/pdf/2501.12948)

## What was broken

Step 10's chains of thought are written by people, either as examples in the prompt or as training data. The DeepSeek-R1 authors write that this success is "heavily contingent upon extensive human-annotated demonstrations", which does not scale, and that a model taught to copy human reasoning is capped by the examples it was shown (pages 1 and 2).

## The idea

Reward only the result. DeepSeek-R1-Zero starts from a pre-trained model, skips supervised fine-tuning entirely, and trains with reinforcement learning (pages 2 and 3). The reward is a rule, not a model: an accuracy reward for a correct final answer, checked against the known answer or by running test cases, plus an equally weighted format reward for putting the reasoning between `<think>` tags (Equation 4, pages 3 and 4). Nobody tells the model how to reason. It is the difference between teaching a junior developer your style and simply running the tests on their code.

The model taught itself to think longer. Its average answer grew steadily through training (Figure 1b, page 4), and it started to stop, re-check and try again, including an "aha moment" where an intermediate version writes "Wait, wait. Wait." and re-evaluates its own work (Table 2, page 5). R1-Zero's reasoning was hard to read and mixed English with Chinese, so the final DeepSeek-R1 adds thousands of readable examples before reinforcement learning and further training stages after it (pages 2 and 6, Figure 2).

## Run it

```bash
python papers/11-deepseek-r1/demo.py
```

The first run downloads two models of the same size (about 6.7 GB together, each pinned to one revision): Qwen2.5-1.5B-Instruct, told to work step by step as in step 10, and DeepSeek-R1-Distill-Qwen-1.5B, a small model trained on DeepSeek-R1's reasoning. Both get the same four competition-style problems and the same prompt. Qwen uses greedy decoding and up to 1,024 tokens; R1 uses DeepSeek's recommended sampling (temperature 0.6, top-p 0.95, fixed seed) and up to 4,096 tokens. The problems and their answer keys, computed in code, were committed before either model saw them.

## The paper's numbers

R1-Zero on AIME 2024, an American high-school math competition: average single-try accuracy rose from 15.6% to 77.9% during training, and to 86.7% with a majority vote over many tries (pages 4 and 5).

Single-try accuracy against other models (Table 8, page 41):

| Model | AIME 2024 | MATH-500 |
|---|---|---|
| GPT-4o (May 2024) | 9.3% | 74.6% |
| Claude 3.5 Sonnet (Oct 2024) | 16.0% | 78.3% |
| DeepSeek-V3, built on the same base model without reasoning training (Table 12, page 56) | 39.2% | 90.2% |
| OpenAI o1-1217 | 79.2% | 96.4% |
| DeepSeek-R1 | 79.8% | 97.3% |

Small models can inherit the skill. Fine-tuned on 800,000 samples generated by DeepSeek-R1 (page 60), the 1.5-billion-parameter DeepSeek-R1-Distill-Qwen-1.5B scores 28.9% on AIME 2024 and 83.9% on MATH-500, ahead of GPT-4o on both (Table 15, page 61). At 32 billion parameters, distillation beat running the same reinforcement learning on the small model directly: 72.6% against 47.0% on AIME 2024 (Table 16, page 61).

## What broke next

This method needs an answer a rule can check. The authors note that for tasks such as writing, a reliable reward is hard to build, and a learned reward model invites the policy to find shortcuts, so "scaling up pure RL methods remains an open challenge" there (page 11). They also list missing tool use, such as search engines and calculators (page 10).
